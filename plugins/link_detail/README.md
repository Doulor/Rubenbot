# 链接详细解析

在群里分享一条支持的作品链接，不用 @。插件引用原消息回复：能取到封面时发图，文字列出实际读到的标题、作者、时长、播放量/点赞、发布时间、简介和原链接。各平台公开字段不同；缺失的播放量不会写成 0，公开计数确实为 0 才显示 0。拿不到公开作品信息时只说「抓不到」，不让模型补写。

## 启用

1. WebUI → 插件 → **链接详细解析**，显式启用。新安装时在权限页授予**读消息、发消息、网络**。不用配置 API key、Cookie 或模型。
2. 在详情页单独开关平台，或调整同群同链接冷却（默认 120 秒；0 关闭）、单条消息最多展开数（默认 3，范围 1–3）。保存后热生效。手工配置放在本目录 `config.yaml`，见 `config.example.yaml`。
3. `send_video` 是将来版本的预留开关，默认关闭。**本版即使设为 true，也不下载或发送视频文件。**

## 平台与可读边界

- B 站视频、动态、专栏、直播；抖音、小红书、快手、微信视频号、微博、知乎、小黑盒、A 站、网易云音乐、NGA。
- Instagram、iwara、TikTok、X、YouTube、Pixiv。Pixiv 只接受明确公开且全年龄的插画作品；分级缺失、非公开或 R18 均不展示封面，不处理图片混淆。
- 面向作品分享地址，不把搜索、首页或账户主页当作品。短链及每一跳都受平台域名与公网地址检查。登录、风控、页面改版、地区限制都可能导致失败；平台开关表示会尝试该平台，不代表保证读到。公开接口与页面不可用时不登录、不使用代理解析服务或浏览器下载器。
- 快手短链按跳转后的作品 ID 读取移动页或桌面页数据，兼容新旧两种桌面作品实体。找不到 ID 一致的作品时只报抓不到，不用推荐作品或网页标题代替。
- 封面在宿主内限时取字节，只接受支持的静态图片；单跳不跟重定向，超过 4 MiB、超时或内容不是图片时退化为文字。不会把任意远程 URL 交给协议端下载。

## 与通用链接阅读的关系

插件是**群内自动回复**，不是第 25 项的 `link.mode: auto`（后者是给策划预取参考）。关闭插件、缺少权限、未覆盖的平台或关闭的平台，仍按主配置 `link` 处理。群聊消息先按原文入库，再运行插件；已送达详情或失败回执的链接不重复交由 core 阅读。混发时保留本轮未接管的网址。同群重复的链接不刷屏，不跨群去重。私聊维持原逻辑。

## 核验

在测试群依次发送一条 B 站视频、一条抖音或小红书作品、一条 X 帖子。前两条应回复可取得的封面与信息；对公开接口被拦的 X 帖子，应只报抓不到，而非编出推文。再把普通网页与作品链接发在同一条消息里：只有作品由插件展开。离线用例为 `tests/test_link_detail*.py`，不依赖平台在线；它们不替代真实群的出站验收。
